# Картонный город — «Город на скотче»

Вертикальный мультшорт 1080×1920, 30 fps, 27,7 с. Город целиком из картона: коробки-дома с клапанами и скотчем,
гофрированные срезы, машины и деревья из картона, река из бумаги, холмы из яичных лотков. Жители — вырезанные из картона фигурки.

**Сюжет:** город держится только на скотче. Скотч кончился: у ратуши отклеилась крыша, коробки раскрылись,
мост сложился, как открытка. Мэр нашёл последний рулон… это было солнце. Город склеили, но солнца больше нет.

- `web/` — движок (three.js r160 + toon/ink/DOF из cartoon-short-kit), `cardpaint.js` — картонные текстуры, `story.js` — раскадровка по словам.
- `voice.mp3` — озвучка (ElevenLabs, голос Ivan), `work/words.json` — тайминги слов, `work/PLAN.md` — план кадров.
- `audio.py` → `music.wav`, `sfx.wav`; `mix.py` — музыка и звуки ровно на 50 % (−6 дБ) от голоса; `captions.py` — анимированные субтитры по словам.

Сборка: `bash <kit>/tools/setup.sh .` (ставит three.js и toon-библиотеку), затем
`node render.mjs frames "0-830"`, `python3 audio.py && python3 mix.py voice.mp3 music.wav sfx.wav`, `bash finish.sh "Gorod na skotche"`.
